# Working contract

Own only this repository. Respect the engine and outreach projects' ownership.
User feedback is a hypothesis about intent; evaluate it against reproducible
observations and explain evidence-based changes of direction.
Do not fabricate provenance or broaden claims beyond tested inputs.
Keep intent in Gooo and reference observations independent of its implementation.
Run `python3 -m unittest discover -s tests` and the bounded bridge verification.
Accept changes using required CI on the exact revision, without human review
requirements. Never bypass a failed or missing check. Record failures honestly.
No paid services, background polling, autonomous recurring runs, or upstream
messages by default. Keep one bounded runner job and timeouts; expand only when
an observed failure or accepted bridge requires it.
