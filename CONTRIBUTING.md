# Contributing

Open one small issue with an OSS language, pinned source URL and license,
observable behavior, input domain, exclusions and a useful upstream outcome.
Provide an independently authored `.gooo` activity with stable semantic IDs,
a native reference runner, finite comparisons and preserved failure evidence.
Never translate an entire project before validating a small useful behavior.

Start locally with Python floor division. Preserve counterexamples such as
negative operands; do not merely add positive examples to raise pass counts.
CI acceptance requires the exact PR revision, all checks successful, and the
original receipts. No human approval is required by this repository's policy.
Only GitHub rules actually configured enforce that policy.

External PRs must follow each upstream project's contribution policy and solve
a real issue. Record proposed, submitted and accepted contributions separately.
English is the shared documentation language; Korean issue reports are welcome.
